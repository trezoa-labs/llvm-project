This trezoa is an extremely simple example of using some simple pieces of the 
LLVM API.  The actual executable generated by this trezoa simply emits an 
LLVM bitcode file to standard output.  It is designed to show some basic 
usage of LLVM APIs, and how to link to LLVM libraries.
